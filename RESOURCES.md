# SSH Deployment Key Resources

## Knowledge

- [OpenSSH `ssh-keygen(1)` manual](https://man.openbsd.org/ssh-keygen)
  Primary reference for creating Ed25519 identities, passphrases, key files, and fingerprints.
- [OpenSSH `sshd(8)` authorized keys format](https://man.openbsd.org/sshd#AUTHORIZED_KEYS_FILE_FORMAT)
  Primary reference for `authorized_keys`, file permissions, and per-key restrictions such as `restrict`.
- [OpenSSH `ssh(1)` client manual](https://man.openbsd.org/ssh)
  Primary reference for identity selection, batch-mode verification, and client connection behavior.

## Wisdom (Communities)

- [OpenSSH mailing lists](https://www.openssh.com/list.html)
  Upstream community for unusual authentication, compatibility, or key-restriction questions.
