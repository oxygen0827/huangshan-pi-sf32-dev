ldcx.tech SSH 部署密钥速查

目标：部署时不再读取桌面 root 密码，同时保留可验证、可撤销的独立凭据。

Mac 私钥只留在本机，并用口令加密。
SSH 认证客户端证明持有私钥，私钥不上传。
服务器公钥写入 /root/.ssh/authorized_keys。

一次性迁移

  1. 生成专用 Ed25519 密钥，设置独立口令。
  2. 把私钥口令加入 macOS Keychain。
  3. 使用旧密码一次，将带 restrict 的公钥追加到服务器。
  4. 配置 SSH 别名，并强制只使用这把密钥。
  5. 用 BatchMode=yes 验证没有密码回退。
  6. 把应急密码移入密码管理器，随后删除桌面明文文件。

核心命令

ssh-keygen -t ed25519 -a 64 \
  -f ~/.ssh/ldcx_vibeboard_deploy \
  -C "vibeboard-deploy@ldcx.tech"

ssh-add --apple-use-keychain ~/.ssh/ldcx_vibeboard_deploy

awk '{print "restrict " $0}' ~/.ssh/ldcx_vibeboard_deploy.pub | \
ssh root@47.102.197.71 \
  'umask 077; mkdir -p /root/.ssh; touch /root/.ssh/authorized_keys; incoming=$(cat); grep -qxF -- "$incoming" /root/.ssh/authorized_keys || printf "%s\n" "$incoming" >> /root/.ssh/authorized_keys; chmod 700 /root/.ssh; chmod 600 /root/.ssh/authorized_keys'

ssh -o BatchMode=yes ldcx-vibeboard \
  'id -u; test -d /home/lincaigui/nginx/static/codex-pet/companion; printf "deploy-key-ok\n"'

顺序不可倒置：保留原密码会话，直到另一个终端里的密钥登录验证成功。不要先删除明文文件，也不要在同一次操作中关闭服务器密码登录。

依据：OpenSSH ssh-keygen(1) 与 sshd(8) authorized_keys。
