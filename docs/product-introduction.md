# VibeBoard / Codex Pet

## 产品介绍

**VibeBoard** 是一套基于立创黄山派的低功耗智能硬件平台。它把一块带有 AMOLED 触摸屏、蓝牙、音频和运动传感器的开发板，做成一个可以安装 App、连接电脑和手机、持续扩展的产品底座。

当前第一款产品形态是 **Codex Pet：桌面 AI 工作状态伴侣**。它放在电脑旁边，通过蓝牙接收 Codex Desktop 的任务状态，让用户不用一直盯着电脑，也能知道 AI 正在工作、已经完成、遇到错误，或者正在等待审批。

> 当前阶段：开发者产品 / 原型产品。整机外壳、最终尺寸、量产 BOM 和正式零售价尚未定稿。

[查看 PDF 版本](product-introduction.pdf)

## 核心体验

- **实时状态展示**：显示 Codex 任务连接、运行、完成、阻塞、等待输入等状态。
- **桌面宠物**：宠物会根据任务状态播放待机、工作、等待、报错和完成动画。
- **审批交互**：遇到命令执行或文件修改审批时，板端显示 `Allow / Deny`，可通过物理按键处理。
- **任务切换**：在屏幕中部左右滑动，切换当前监控的 Codex 任务。
- **轻量互动**：点击宠物触发跳跃等动画，RGB 指示灯随系统状态变化。
- **可扩展 App**：固件烧录一次后，可以通过 BLE 从 Mac 或 iPhone 安装新的 Runtime App，不需要每次重新刷固件。

## 平台能力

VibeBoard 不只运行 Codex Pet，也可以作为通用智能硬件平台使用：

- Lua 5.5 Runtime 和受控 LVGL UI 能力
- App 安装、启动、停止、删除和恢复
- 时钟、番茄钟、2048、贪吃蛇、打砖块等小游戏
- 加速度、陀螺仪、姿态和运动类应用
- 电池电压、充电状态、屏幕亮度、触摸和物理按键读取
- RGB 灯控制、信息流展示和提醒
- PCM WAV 音频播放，以及受控的短录音接口
- 手机/桌面端注入天气、AI 回复和其他云端信息

网络和云端能力由电脑或手机 Companion 负责，板子默认不直接提供 Wi-Fi、HTTP 服务或稳定的局域网地址。这样可以避免在设备上配置热点密码，也让板端 Runtime 保持简单、低功耗和可控。

## 传感器规格与实测边界

官方板卡资料宣传的是“九轴传感器 + 光感”，理论器件组合为：

- `LSM6DSL`：三轴加速度计 + 三轴陀螺仪
- `MMC56X3`：三轴磁力计，可用于电子罗盘
- `LTR303`：环境光传感器

当前这块实板的 I2C 探测结果是：

- `LSM6DSL` 在 `0x6a` 应答，已确认在线
- `LTR303` 在 `0x29` 未应答
- `MMC56X3` 在 `0x30` 未应答

因此当前可以稳定承诺的是：

- 加速度和陀螺仪数据
- 基于 IMU 的姿态、倾斜、运动和手势类功能
- 步数等运动应用接口（仍需按最终产品算法做实测）

光照和电子罗盘暂时不能当作当前产品的确定功能对外承诺。项目 Runtime 会先探测硬件，缺失传感器时降级显示，不会因为 I2C 未应答而崩溃。

## 尺寸规划

当前项目已经确定的是显示规格，不是整机毫米尺寸：

- 屏幕：390 × 450 像素，约 1.85 英寸
- 主控模组：约 27.9 × 18.7 mm 级别
- 整块开发板和最终外壳：尚未形成正式产品图纸

如果继续做桌面 Codex Pet，建议第一版外壳先按 **约 68 × 48 mm 的小型设备**规划，再根据电池、扬声器、按键和天线空间调整厚度。这个尺寸只能作为产品定义起点，不能视为最终量产规格。

## 价格规划

项目目前没有正式售价。作为成本和定位参考：

- 黄山派开发板公开资料的常规价格约为 **133 元**
- 过去曾有 **98 元**的限时活动价，该活动不应当视为长期价格
- 完整 Codex Pet 套装还需要增加外壳、电池、扬声器、装配、包装和 Companion 体验

建议的首版价格梯度：

| 版本 | 建议售价 |
| --- | ---: |
| 开发者裸板版 | 129～149 元 |
| Codex Pet 基础套装 | 199～249 元 |
| 完整外壳/电池/扬声器套装 | 249～299 元 |

当前比较合适的产品锚定价是 **249 元左右**。这个价格对应的是“AI 桌面伴侣 + 可编程硬件平台”，而不是具备防水、心率、GPS 和成熟健康功能的消费级智能手表。

## 产品定位

VibeBoard 的差异化不在于替代 Apple Watch，而在于：

1. 它是一个有真实屏幕和实体交互的 AI 状态终端。
2. 它能把 Codex 的工作过程从电脑窗口带到现实桌面。
3. 它不是一次性 Demo，而是可以持续安装新 App 的硬件平台。
4. 它同时适合开发者工具、桌面宠物、传感器实验、小游戏和智能穿戴原型。
